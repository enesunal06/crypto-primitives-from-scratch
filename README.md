# Crypto Primitives From Scratch

Implementing the core cryptographic primitives behind 
Bitcoin and Ethereum from scratch in Python — no crypto 
libraries, pure mathematics.

## Motivation

This project bridges theoretical mathematics — especially 
group theory and finite fields — with practical blockchain 
cryptography.

## Stages

- [x] Stage 1: Finite Fields
- [x] Stage 2: Elliptic Curves over Finite Fields
- [x] Stage 3: ECDSA (Signing & Verification)
- [x] Stage 4: Merkle Trees
- [ ] Stage 5: Ethereum-compatible Wallet
## Principles

- No external cryptography libraries
- Everything implemented from first principles
- Focus on mathematical correctness and clarity
